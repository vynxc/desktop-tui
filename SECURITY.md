# Security policy

Desktop TUI runs a local renderer as the current user and can load custom JSON
templates and GLB files from paths the user selects.

Please report vulnerabilities privately through
[GitHub Security Advisories](https://github.com/vynxc/desktop-tui/security/advisories/new).
Do not open a public issue for a vulnerability that could execute code, expose
local data, or corrupt a Plasma session.

Only the latest release receives security fixes.
